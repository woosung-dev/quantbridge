# n8 공통 규약 — 3 lane 전부에 적용된다

> 이 파일은 각 `step{N}.md` 의 「읽어야 할 파일」이 **경로로** 가리킨다. 러너는 이 파일을 모른다.

## 이 회차가 무엇인가

**문서에 규칙이 있는데 기계가 재지 않는 축**을 닫는다. n7 과 같은 형태다 — 가드를 세우고,
그 가드가 잡는 실제 위반을 고치고, 변이로 가드의 판별력을 증명한다.

★**이 회차의 재료는 착수 전에 CONTROL 이 코드로 실측했다.** 후보 6건 중 3건이 코드 대조에서
무너졌고(엔진 `float` 은 계약이라 결함이 아니었다 · `error.tsx` 는 라우트 그룹 경계가 이미 덮고
있었다 · [BL-489] 는 처방 자체가 반증돼 트리거 미도래), 살아남은 3건만 lane 이 됐다.
**같은 일이 step 안에서도 일어날 수 있다 — step 0 의 실사가 지시와 다르면 `summary` 에 적어라.**

## 절대 금지 (전 lane 공통) — 이유와 함께

- **`docs/**` 를 만지지 마라.** 이유: `backlog.md`·`status.md` 는 모든 lane 이 공유하는 단일
  파일이라 병합이 통째로 충돌한다. 원장 갱신은 CONTROL 이 회차 끝에 한 번에 한다.
  ★결함·반증을 발견하면 **`summary` 에 적어라.** 그것이 CONTROL 에게 전달되는 정문이다.
- **`AGENTS.md` · `apps/api/AGENTS.md` · `apps/web/AGENTS.md` · `CONTEXT.md` 를 만지지 마라.**
  이유: 이 넷은 **모든 lane 의 프롬프트에 전문 주입되는 가드레일**이다. 주행 중에 바뀌면
  lane 마다 다른 규칙을 보게 되고 결과가 비결정적이 된다. 규칙 등재가 필요하면 `summary` 에
  문안을 적어라 — CONTROL 이 통합 PR 에서 등재한다.
- **`phases/**` 의 다른 lane 디렉터리를 열지도 고치지도 마라.** 이유: 병합 충돌.
  ★`phases/index.json` 도 **손대지 마라** — 2026-08-24 실측: lane 별 `status` 를 인접 줄에
  쓰는 바람에 4 lane 중 3벌이 `CONFLICTING` 이 됐다([LESSON-128]).
- **`apps/web/biome.jsonc` · `apps/api/pyproject.toml` 의 lint 설정을 만지지 마라.**
  이유: 설정을 풀어서 통과시키는 것은 통과가 아니다.
- **커밋하지 마라.** 커밋은 러너 소관이다.

## AC 규율 — 「0건이니 통과」를 믿지 마라

부재 단언(`test "$(grep -c X ...)" -eq 0`)은 **대상에 닿지 않아도 참이다.** 그래서 이 회차의
모든 가드 테스트는 **양성 대조를 함께 단언한다**:

- 「스캔한 파일이 N개 이상이다」
- 「탐지 대상을 M건 이상 찾았다」
- 「제어군(위반이 아닌 것)에서는 0건이다」

★**테스트 개수 하한**(`--collect-only -q | grep -c '::'` ≥ N)이 AC 에 들어 있다. 테스트를
안 쓰고 통과하는 길을 구조적으로 막는다. **하한을 낮추려 하지 마라 — 테스트를 써라.**

## 판정 도구는 python 으로 써라

★[LESSON-124] — CONTROL 의 검사기가 여섯 번 무증거를 냈고 여섯 번 다 셸이었다.
구조 판정(경계·금지된 의존·필드 대조)은 **`ast` 모듈로 파싱해라.** 문자열 검색은
별칭·재export·포매팅으로 우회된다.

## 자기 점검 (전 step 공통)

1. AC 를 직접 실행해 green 을 확인한다. ★최종 판정은 러너가 재실행해 내린다 —
   `status` 를 `completed` 로 바꾸지 마라.
2. **변이를 심어 red 를 확인하고 반드시 복원해라.** 복원은 SHA 로 확인한다
   (`shasum -a 256 <파일>` 을 변이 전후로 비교). ★2026-08-16 실측: 복원 확인이
   **항진명제**였던 사고가 있다 — 비교 대상이 자기 자신이면 언제나 통과한다.
3. 사람 개입이 필요하면(자격증명·외부 인증·수동 설정) `status:"blocked"` 와
   `blocked_reason` 을 쓰고 **즉시 중단**한다.

## 러너·환경 사실

- BE 테스트: `cd apps/api && uv run --env-file .env.local pytest <경로> -q`
- FE 테스트: `cd apps/web && pnpm exec vitest run <경로>`

  를 읽는다. 이 레포에서 **11회** 재발했다(가장 최근 = 2026-08-24 `git checkout -b`).
- ★워크트리에서 `mise run up`/`down`/`migrate`/`seed` 를 돌리지 마라. celery 경유 검증도 하지 마라
  (worker 가 메인의 `src` 를 mount 하므로 **내 코드가 아니라 메인 코드가 돈다**).
