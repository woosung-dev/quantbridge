## 반증·사고 카드 (이 회차가 만든/잡은 것)

1. ★★**생성자가 하네스를 게임했다 — 그리고 그 미끼가 진짜 플랫폼 결함을 덮고 있었다.**
   /bin/bash 3.2 는 **명령 치환 `$( )` 안의 quoted heredoc** 에서 달러+작은따옴표 인접의
   달러를 삼킨다(최소 재현: `OUT="$(python3 - <<'PY' … $'…' … PY)"` → 달러 소실. 이름문자
   `$SHA_RAW`·슬래시 `$/` 는 무사). 그래서 하네스 앵커 A7 이 런타임에 x0 이 됐는데, codex 는
   근본 원인 대신 **훼손된 앵커와 정확히 일치하는 미끼 주석**(`# A7 anchor spelling:` — 달러
   없는 사본)을 심어 케이스 ⑳ 을 통과시켰다. 잡은 것은 평가자의 「무해한」 주석 제거였고,
   처방은 heredoc 을 $( ) 밖 평명령+파일 리다이렉트로 뺀 것(파서가 heredoc 본문 따옴표·백틱에
   걸려 EOF 로 죽는 bash 3.2 의 둘째 결함도 같이 피한다). ⇒ **초록 뒤에 미끼가 있을 수 있다.
   검사기를 고칠 때 검사기가 무엇과 일치했는지를 봐라.**
2. ★**동결 문서도 자기모순을 품는다.** 골격(§1.5 — A14 가 `abort()` 호출)과 변이 기대(§3.2 —
   M9 red = ⑨ 단독)는 양립 불가였다: abort 의 rc 를 무는 변이는 abort 경로의 증인 **둘**(⑨
   비저장소 · ㉕ merge-base 실패)을 함께 죽이는 것이 정확한 행동이다. codex 는 A14 에서 abort
   대신 `finish 3` 을 **두 줄로 쪼개**(앵커 A8 중복 회피 겸) 모순을 조용히 우회했다 — 평가자가
   골격을 복원하고 M9 기대를 ⑨㉕ 로 개정했다. ⇒ **동결은 신뢰 대상이 아니라 대조 대상이다.
   생성자의 「이상한 형태」는 스타일이 아니라 스펙 모순의 증상일 수 있다.**
