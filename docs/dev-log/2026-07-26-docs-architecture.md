## 문제

## 진단 — 문서가 없는 게 아니라, 있는데 안 보였다

층 구조는 **이미 존재하고 대체로 옳다.**

| 층  | 답하는 질문                     | 문서                                                 | 지평      |
| --- | ------------------------------- | ---------------------------------------------------- | --------- |
| 1   | 왜·누구를 위해 만드나           | `docs/00_project/vision.md` · `positioning.md`       | 영구      |
| 2   | 어떤 순서로 성장하나            | `docs/00_project/roadmap.md` (Horizon×Pillar)        | 분기~년   |
| 3   | **뭐가 남았나 (전체)**          | **`docs/product-roadmap.md`** — 남은 103건, 그룹 1~5 | 주~월     |
| 4   | **지금 뭘 하나 (다음 한 걸음)** | **`docs/TODO.md`**                                   | 세션      |
| 5   | 그 항목이 정확히 뭔가           | `docs/REFACTORING-BACKLOG.md`                        | 참조      |

| 7   | 이 기능이 뭘 보장/미보장하나    | 스프린트별 `operating-contract.md`                   | 기능 수명 |

**3층과 4층은 지평이 달라서 합치면 안 된다.** 합치면 919줄짜리가 하나 더 생길 뿐이다.

### 그런데 왜 "전체 그림 문서가 없다" 고 느껴졌나 — 원인 3개

1. **`QUANTBRIDGE_PRD.md`(1,724줄) 가 루트에서 권위 있어 보인다.** 이름이 PRD 인데 머리말은 스스로 **LEGACY(2026-04-14, 미개정)** 라고 자백하고 "백테스트 엔진·라이브러리·Phase 타임라인이 현재 구현과 다르다" 고 경고한다. 루트에 있으니 전체 그림을 찾을 때 먼저 열게 되고, 틀린 내용을 만난다.
2. **roadmap 이 두 개고 이름이 비슷하다.** `00_project/roadmap.md`(전략, BL 언급 5회, **2026-04-21 이후 미수정**) ↔ `product-roadmap.md`(실행 백로그, BL 언급 **124회**, 매 스프린트 갱신). 역할은 실제로 다른데 이름으론 구분이 안 된다.
3. **TODO 가 "다음 한 걸음" 으로 안 읽힌다.** 과거 14절을 안고 919줄이라 아카이브처럼 보인다. 그 공백을 메우려고 `checklist.md` 와 킥오프가 생겨 중복이 커졌다 — dogfood-restore 세션이 그걸 더 키웠다.

## 결정 — 문서를 늘리지도 병합하지도 않는다

구조는 옳으므로 **가시성만 고친다.** 아래 4개는 서로 독립이라 부분 실행 가능.

### D1. `QUANTBRIDGE_PRD.md` 를 루트에서 치운다

`docs/archive/` 로 이동. 역사적 참조는 남기되 "전체 그림" 을 찾는 사람이 먼저 열지 않게 한다. 참조하는 문서가 있으면 링크만 갱신.

### D2. 두 roadmap 을 이름으로 구분한다

`00_project/roadmap.md` → 전략 로드맵임이 이름에 드러나게(예: `strategy-roadmap.md`). 이름 변경이 부담이면 **양쪽 머리에 2줄 배너**("이건 전략 지평 / 실행 백로그는 저기")로 대체 가능. **stale(3개월) 여부도 같이 판단할 것** — 살릴지 archive 할지.

### D3. `docs/TODO.md` 다이어트

과거 스프린트 14절 삭제(**dev-log 에 이미 있다 — 삭제 전 각 스프린트가 dev-log 에 실제로 있는지 1건씩 확인**). 남길 것 = 활성 스프린트 + **다음 세션 인수인계**. 919 → 약 150줄 목표.

### D4. `checklist.md` · `~/.claude/plans/` 킥오프 폐지

둘 다 `docs/TODO.md` 의 "다음 세션" 절로 흡수. 신규 스프린트부터 `checklist.md`·`context-notes.md` 를 만들지 않는다(전자 → TODO, 후자 → dev-log 회고). **과거 15폴더는 손대지 않는다** — 이력 보존.

`operating-contract.md` 는 **유지**한다. 7층의 고유 질문을 답하고, 이번 dogfood 에서 실제로 검증 체크리스트로 쓰였다.

### D5. 반복 함정을 1곳으로 승격

13개 문서에 복붙된 항목(`pnpm test --run` exit 0 · BE pytest 3-env export · `format:check` 는 게이트 아님 · compose `--no-deps` 등)을 **`AGENTS.md` 또는 `docs/guides/` 한 곳**으로 올린다. 스프린트 문서는 그걸 **가리키기만** 한다.

## 이후의 규약

- **다음 세션은 `docs/TODO.md` 하나만 열고 시작한다.** 필요하면 TODO 가 다른 문서를 가리킨다.
- 붙여넣는 프롬프트는 **가리키기만** 한다. 내용을 들고 있지 않는다 — 레포 밖 문서가 진실을 갖는 순간 다음 세션이 못 찾는다.
- 새 문서를 만들기 전에 **"이게 답하는 질문이 위 7층 중 어디인가"** 를 먼저 답한다. 답이 기존 층과 겹치면 만들지 않고 기존 문서에 쓴다.
