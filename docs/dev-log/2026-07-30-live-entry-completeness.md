## 2. ★★계측기가 스스로를 검증했다 — 그리고 직전 회차의 라벨을 반증했다

새 도구를 **직전 회차가 16.7% 를 뽑은 그 창**(07-29 leg2, 세션 `a2c96422`)에 소급 적용했다.

```
층위1 시도 확정 거절률                       16.67%   ← 직전 헤드라인 16.7% 와 일치
층위2 에피소드(체결 끊기, 채택)               0.00%
층위2 에피소드(체결/거절 끊기, 반대 해석)    12.50%
```

두 가지가 동시에 증명됐다:

1. ★**캘리브레이션** — 알려진 값을 **독립 구현이 원장에서 다시 뽑았다.** 손으로 뺀 숫자가 아니다.
2. ★★**직전 회차의 "유실률 16.7%" 는 에피소드 유실률이 아니라 시도 거절률이었다.**
   같은 데이터에 답이 셋이고, 그 회차는 **어느 층위인지 말하지 않은 채** "유실률" 이라고 적었다.
   → 새 값과 16.7% 를 나란히 놓으려면 **층위를 맞춰야** 한다.

★**"감소" 를 개선으로 주장하지 않는다.** 직전 창 16.67% → 이번 창 0% 지만 기간·시장조건이 다르고
(이번 창 레인지 **0.65%**), 거절 1건은 표본 잡음 범위다.

  자리에서 `✓` 만 찍고 워커를 `idle` 로 방치했다.
- **BL-554** pre-push 가 현재 브랜치로 판정 → **stdin 4-튜플의 실제 push ref** 로.
  ★**main 보호는 `remote_ref` 를 가장 먼저** 본다(`feat/foo:main` 우회 차단).
- **BL-555** `stage/*` 화이트리스트 추가. 부수로 태그 push 정책 명시(회귀 차단).

★워커가 스펙 밖에서 구멍 2개를 더 막았다 — 화이트리스트를 remote·local **둘 다** 검사,
삭제 sha 를 **길이까지** 검사(`0`·`000` 을 삭제로 인정하면 fail-open).

★**구현 판단 하나를 옮겨 적을 만하다** — Enter 를 밀어도 되는 조건을 **fail-closed 허용목록**

_"안 밀어서 잃는 것은 자동 복구 한 번, 잘못 밀어서 잃는 것은 사람의 승인 결정. 비대칭이므로 닫는 쪽으로 기운다."_
