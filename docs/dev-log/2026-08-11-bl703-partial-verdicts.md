## 무엇을 했나

`docs-audit.sh` 의 `trigger_verdicts` 축이 `if verdict != "PARTIAL"` 로 PARTIAL 을 면제하고
있었다. 그 면제가 [BL-702] 의 ⓪ 표 술어 `살아 있는 행 == ACTIVE ∪ (PARTIAL ∧ 도래)` 에서
**오른쪽 항을 구조적 공집합**으로 만들었다 — 판정줄이 없으면 「도래」로 판별될 수가 없다.
술어는 완성돼 있었고 데이터가 생길 수 없었다.

순서는 계약이었다: **판정 24/24 → 의무 확대.** 뒤집으면 24건이 즉시 red 다.

1. `bl-trigger-sweep.sh` 대상을 `ACTIVE ∪ PARTIAL` 로 (33건, 커버리지 33/33)
2. PARTIAL 24건 판정 — 각 건에 코드·게이트·본문 인용
3. ⓪ 표에 도래 5건을 행 **O~S** 로
4. `docs-audit.sh` 의 면제 제거
5. `docs-audit-test.sh` 에 PARTIAL 케이스 3종
