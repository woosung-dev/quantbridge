## 검사기가 못 본 것 3종 (전부 이 회차 실측)

### ① 정적 게이트 3종이 「기동 불가」를 통과시켰다

playwright config 첫 구현이 `import.meta` 를 썼고, playwright 는 config 를 **CJS require** 로 읽는다:

```
ReferenceError: exports is not defined in ES module scope
    at frontend/playwright.config.ts:3:23
    at loadESMFromCJS (node:internal/modules/cjs/loader:1600:24)
```

3종 e2e 전부 rc=1 = 기동 불가. 그런데 `typecheck` rc=0 · `lint` rc=0 · `vitest` **1346 passed**
였고 그 vitest 에는 **그 config 를 실제로 import 하는** `e2e-project-wiring.test.ts:68-78` 이 들어
있다. **vitest 는 ESM 로더, playwright 는 CJS 로더 — 같은 파일을 두 모듈 시스템이 다르게 읽는다.**

### ② 로컬이 한 번도 안 탄 경로가 CI 에만 있었다

로컬은 항상 `PLAYWRIGHT_BASE_URL` 을 줬으므로 `webServer` 블록이 실행되지 않았다:

```
[WebServer] > next dev -- --port 3100
[WebServer] Invalid project directory provided, no such directory: .../frontend/--port
```

`pnpm dev -- --port N` 은 이 pnpm 에서 `--` 를 그대로 전달한다. 빈 포트로 `pnpm dev --port 3199` 를
직접 돌려 `- Local: http://localhost:3199` + `✓ Ready in 302ms` 로 수정을 증명했다.

### ③ 사본이 2벌이 아니라 5벌이었다

`?? "http://localhost:3000"` 폴백이 config 외에 spec **4개**에 복제돼 있었다. 서버를 3100 으로
옮기자 그 4개가 3000 을 찔러 **190ms 만에** 죽었다(CI design-canon 전건). 해석기를
`frontend/e2e/_base-url.ts` **1벌**로 모았고 `grep -rn 'localhost:3000' frontend/e2e/` = **0건**.
