## 집합 정의

- **B** = 전구간 백테스트 진입 집합 — `btgap_compare.py run` (기존 도구), 채점 창 필터.
- **R** = 라이브 프로토콜 재생 진입 집합 — 신규 `replay`: 매 봉 t 마다 직전 300봉 창으로
  `run_live`(Option B, `backend/src/strategy/pine_v2/event_loop.py:416`)를 재실행해 마지막 봉
  이벤트만 채택. **원장 인자 4종 미주입**(`ledger_seed_legs`·`ledger_conditional_fills`·
  `position_epoch`·`emit_from_bar_time`) — 백테스트 순수성.
- **R′** = R 에서 세션 창(위 4창) 밖 진입을 제거한 집합.
- **L** = 라이브 실측 진입 — orders 덤프의 `idempotency_key` 를 `parse_live_entry_key` 로
  파싱(엔진 무경유 오라클). 예상 |L|≈92(93 − 수동 flatten 1), 정확 수는 도구가 확정.
- **매칭 규약**(직전 회차 확정본 재사용): 키 = `bar_epoch` ±3봉 + 방향 + `trade_id`
  (`ENTRY_BAR_TOLERANCE_BARS=3`), 가격 근접은 술어가 아니라 검증용. `filled_at` 금지.
  X↔L 매칭률 = |매칭쌍| ÷ |L| (분모 L 고정, 행별). B↔R 는 분모 |B| 를 표에 병기.
- ★R 의 「신호봉」과 L 의 `bar_epoch`(장전봉)가 같은 단계인지 측정 전에 코드로 확인하고
  매칭 의미를 보고서에 적는다(직전 실측: 체결은 장전봉 +1~2봉).

### 정정 이력 (측정 전, 2026-08-06T14:5xZ)

- **③ → ③′ 교체**: 원안 「R′↔L − R↔L(분모 L 고정) ≤ +10%p」는 R′⊂R + 분모 고정이라
  변화가 구조적으로 ≤ 0 — **이상화에서 항진명제**(CONTROL 자체 발견 + eval(codex) 기각영역
  검증 교차 일치. eval 은 `match_entries()` 의 ambiguous 재배분 경로로 완전 항진은 아니되
  「단순 subset 산술로 판정 금지」를 판정). LESSON-072 의 절차대로 **측정 전에** 분모를
  각 집합 크기로 바꾼 정밀도 기준으로 교체했다. 측정 시 ambiguous 수와 제거 전후 pair
  증감을 병기한다(eval 권고).
- eval 판정 요약: ① 기각가능(R key = `last_bar_time` 정렬 조건 — gen 이 코드로 확인) ·
  ② 기각가능(부호 비고정 — `PersistentStore` fresh 리셋이 진입을 늘릴 수도) ·
  ④(a) 조건부(유효 계약 내 불일치 = 측정 무효 신호) · ④(b)(c) 기각가능.

### 정정 이력 2차 (측정 전, 2026-08-06T15:1xZ — eval2 독립 실측 반영)

- **|L| = 90 으로 정정**(원문 「예상 ≈92 = 93 − 수동 flatten 1」은 오류): 수동 flatten 류
  비진입(NULL key·reduce_only) 행이 **3건**이고, 그중 2건은 직전 회차 덤프에 없다가 이번에
  **소급 등장**했다(둘 다 직전 캡처보다 먼저 체결된 행 — 세션 비활성화 직후 2.0s/5.3s 의
  정리 주문). 「신규 체결 8건」도 「신규 진입 6건 + 비진입 소급 2건」으로 정정.
  ⇒ **④(b) 는 「공통 행 필드 불변(84/84)」은 참이나 「행 집합 불변」은 거짓** — 원인은
  [확인 필요](직전 덤프 SQL 미보존, `DISTINCT ON(idempotency_key)` 류가 NULL 3행을 1행으로
  접었다는 가설이 관측과 정합). 이번 회차 덤프(`state='filled'` 순수 필터)를 정본으로 한다.
- **① 해석 한정(관측량·문턱 불변)**: B 는 **체결봉** 키(`BacktestTrade.entry_time`), L·R 은
  **장전봉** 키 — B↔L 만 단계가 한 칸 어긋난 채 ±3봉으로 재므로, ① 의 차이에는 동인 ⑴ 외에
  **단계 불일치 성분**이 섞인다(직전 실측: B↔L 매칭 여부가 「라이브 체결 지연 ≤3봉」으로
  설명 — 오즈비 166.2, Fisher p=1.4e-16; 같은 집합에서 키 규약만 바꾸면 44.4%↔100%).
  ⇒ 판정 시 **B↔L(체결봉 키잉) 재매칭을 반드시 병기**하고, ⑴ 의 기여는
  「R↔L − B↔L(체결봉)」 축으로 읽는다. R↔L(장전) vs R↔L(체결) 일치 여부로 R 의 단계
  정합도 함께 검증(갈리면 R 정의 위반). 매칭 지연 감도표(±3 대신 관측 p90=11봉) 병기.
- **R′ 창 규약 고정**: 세션 창 포함 판정은 **봉 종료 시각(`bar_epoch`+60s)** 기준. 봉 시작
  기준이면 세션 첫 진입 2건(L 실측 — 봉 시작이 세션 생성보다 22.7s/25.2s 이름)이 인공적으로
  제외된다. 이 2건은 어느 규약이든 각주로 남긴다.
- 세션 공백 정정: 3구간(7.596%) + **머리 22.676s**(채점 창 시작~첫 세션 생성). 공백에 완전
  포함되는 봉 166개 — ③′ 판별력 조건 충족 전망(기대 7~16건).
- ⑵(트리거 드리프트)는 직접 실험하지 않는다 — R↔L 잔차로 상계만 적는다(A/B 설계상
  잔차 = ⑵ + 원장 체결 권한(ADR-025) + 미모형 요소).
