## ★★final-gates §5 — 전제는 **죽은 게 아니라 휴면**이었다

R1 에서 §5 「CI 커버리지 잡」을 기본 skip 으로 돌리며 주석을 이렇게 고쳤다:
「원래 근거는 _CI 는 러너 전역 미할당으로 `steps=0` 에 죽는다_ 였다 — **그 전제는 이제 거짓이다**」
(`7cbf01b9`, 2026-08-06 **04:03Z**, 근거 = 최근 12 run 전건 완주).

**3시간 22분 뒤 재발했다.** run `31079229987`(**07:25:38Z**, PR #550)에서 `backend_coverage` 와
`ci` 가 **`steps=0` · failure** — 같은 브랜치의 직전 run(06:36Z)은 전건 성공이었다.

⇒ 「이제 거짓이다」는 **관측이지 성질이 아니었다.** 12 run 은 그 시점의 표본일 뿐이다.
이 회차에서 그 주석을 **휴면**으로 완화했다. **기본 skip 판단 자체는 바꾸지 않는다** — 중복
근거(무계측 298.97s vs 계측 529.16s, 배율 **1.770**)는 러너 사정과 독립적으로 여전히 유효하다.
