## 1. TL;DR

- **데모 트레이딩 후보: 없음.** 8종(runnable 7종) 어느 것도 두 국면(2024 상승장 · 최근 1년)에서 동시에 플러스가 아니다. 2024 승자(PbR/RsiD/bs)는 최근 국면에서 전부 붕괴하고, 최근 국면 유일 플러스인 DrFX 는 2024 에서 마이너스다. → **그대로 라이브/데모에 올릴 전략 0** (이전 QA 결론 재확인).
- **정규화 효과**: qty=1 폴백이던 4종(LuxAlgo/PbR/UtBot×2/bs)이 100% equity 기준으로 압축됨(예: PbR 2024 4h **+343.8% → +113.4%**, bs 2024 4h **+238.9% → +35.2%**, UtBot recent 1h **−2429% → −286%**). **부호·트레이드 수는 불변** — 사이징은 시그널 타이밍을 안 바꾸므로 상대 순위는 보존, 스케일만 공정화.
- **Pine > form 우선순위 실증**: `strategy(default_qty_type=...)` 선언 스크립트(DrFX=`percent_of_equity 100`, RsiD=`fixed 2`)는 **정규화 무효**(before=after 완전 동일) — 엔진 우선순위가 코드로 확인됨.

## 4. 국면 민감도 (2024 상승장 vs 최근 1년)

- **전형적 long-bias 붕괴 패턴**: 2024(BTC 상승장)에서 플러스인 PbR(+113%)·RsiD(+244%)·bs(+35%)가 최근 1년(횡보·하락 혼재)에서 −58%/−769%/−50% 로 전부 반전. 추세추종/돌파 계열이 상승장에서만 작동.
- **역방향 유일 예외 DrFX**: 2024 −17.8% / recent +25.9% — 최근 국면에서 유일하게 플러스. 단 2024 마이너스라 "국면 무관 강건"은 아님. MDD 는 −32~−56% 로 코호트 중 가장 통제됨.
- **UtBot(ind=strat)**: 두 국면 모두 −70%대 — Track A/S parity 확인(indicator·strategy 트레이드 동일), 그러나 일관되게 손실.
- **공통**: 승률 26~59%, PF 0.71~1.24(RsiD 제외) — 엣지가 약하고 국면 의존적. Sharpe 는 bar-count 스케일이라 TF 간 비교 금지(연율화 아님).

## 5. 데모 트레이딩 후보 판정

**판정: 후보 없음 (No-Go).** 두 국면 동시 플러스 + 안정 PF(>1) + 통제된 MDD 를 만족하는 전략이 0종.

| 관점           | 최선 근접                            | 왜 부적격인가                                     |
| -------------- | ------------------------------------ | ------------------------------------------------- |
| 최근 국면 수익 | **DrFX 4h** (recent +25.9%, PF 1.22) | 2024 −17.8% — 상승장에서 오히려 손실, 엣지 미검증 |
| 2024 수익 크기 | PbR 4h (+113%), RsiD 4h (+244%)      | 최근 국면 −58% / −769% 붕괴 — 과최적/국면 종속    |
| 낮은 변동성    | DrFX 4h (MDD −32~−56%)               | 여전히 net-negative 2024                          |

- **굳이 라이브 파이프라인 exercise 목적의 페이퍼 트레이딩이라면** DrFX 4h 가 least-bad(최근 국면 유일 플러스 + native `percent_of_equity` 사이징 + 통제된 MDD)이나, **수익 추천이 아니라** "가장 덜 위험한 파이프라인 테스트용"이라는 점을 명시. 2024 마이너스 + PF 0.82(2024)라 엣지 근거 부족.
- **권고**: 데모 트레이딩 승격 전에 (a) 국면 무관 강건성 확보(WFO/스트레스), (b) 청산/마진 모델 도입(§6), (c) 최소 파라미터 안정성 검증이 선행돼야 함. 현 코퍼스는 "TV 스크립트 실행 정합" 검증용이지 알파 후보가 아니다.

## 6. 방법론 · 한계 (정직성)

1. **청산/마진 모델 없음** — 엔진은 qty=절대수량 PnL 만 계산, equity 음수 허용 → 정규화 후에도 Ret < −100% 가능(PbR/UtBot/RsiD). 이는 "무한 마진 가정 명목 손실"이며 실계좌라면 이미 청산. 절대 수치가 아니라 **상대 비교·부호·MDD 형상**으로 해석할 것.
2. **RsiD·DrFX 는 Pine 선언 사이징** — `--normalized`(form)로 못 덮음(Pine 우선, 의도된 동작). RsiD(fixed 2)는 ~8x 레버리지라 코호트 비교 제외 권장. 완전 공정 비교하려면 스크립트 소스의 `strategy()` 사이징을 직접 편집해야 함(범위 밖).
3. **Sharpe/Sortino bar-count 스케일** — 연율화 아님, TF 간 직접 비교 금지. CAGR 은 timestamp 기반이라 비교 가능.
4. **엔진 정합 범위** — 본 리런은 사이징 config 만 바꾼 동일 엔진(PR-1 무변경). 값의 TV 절대 정합(특히 ta.ema 워밍업)은 BL-409 로 별도 추적.
5. **1h 결과 생략 근거** — 전 스크립트 1h < 4h (과매매·수수료 누적), 결론(후보 없음) 불변이라 4h 중심 서술. 전량은 `results.json`.
