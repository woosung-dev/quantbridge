- `.pane { display: flex }` 가 브라우저 기본 `[hidden]{display:none}` 을 이겨 **B 패널이 항상 화면 절반을 빈 채로 점유**. 그 결과 A 패널이 675px 로 눌려 **모든 화면이 768px 이하 모바일 레이아웃으로 렌더**되고 있었다. `[hidden]{display:none !important}` 로 수정.
