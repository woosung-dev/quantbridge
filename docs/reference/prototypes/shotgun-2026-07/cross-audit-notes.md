| 무효 입력 modifier | `.input.invalid`(05·16·17) / `.field-input.is-invalid`(05b) | **`.input.invalid`** (선언 내용은 이미 동일) |

### 내부 필드명 노출 여부

`is_degenerate`, `skipped_count`, `phase` 는 **원시 필드명으로 노출된 곳이 없고** 전부 한국어로 서술되어 있다. 예: screen-10-optimizer-detail.html 히트맵의 degenerate 셀은 `aria-label="fastLength 30, slowLength 60, 거래 0건이라 목표값 없음"` + `title="거래가 0건이라 샤프 지수를 계산할 표본이 없습니다."`. 이 서술을 `labels.degenerateReason` 으로 그대로 승격하면 된다.

### 이식 시 주의

`.tabs`/`.tab` 은 22화면 중 **실제 탭 시맨틱이 맞는 곳이 08·08b·15 세 곳뿐**이다(`role="tabpanel"` 보유). 02·03·09·11·01b 는 필터/토글이고 10b 는 정렬 컨트롤이다. React 이식 시 `<Tabs>` 와 `<SegmentedControl>`(aria-pressed 기반) 두 컴포넌트로 나누어야 하며, 하나의 Tabs 로 뭉뚱그리면 지금의 접근성 오류가 코드로 굳는다.
