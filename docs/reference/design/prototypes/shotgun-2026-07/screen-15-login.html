QuantBridge 프로토타입 화면 목록

Pine Script 전략을 검증하고, 검증한 그대로 주문까지 잇습니다.

QuantBridge 는 TradingView 에서 쓰던 Pine Script 를 파싱해 자체 인터프리터로 백테스트하고, 같은 전략을 거래소 주문으로 연결하는 로컬 워크스페이스입니다. 백테스트와 실제 주문이 서로 다른 코드 경로를 타지 않도록 만들었습니다.

01 확인 가능한 사실

숫자 자랑 대신 정책을 적습니다.

사용자 수나 체결 속도처럼 이 화면에서 확인할 수 없는 수치는 싣지 않습니다. 대신 코드와 문서로 확인할 수 있는 규칙 네 가지를 적습니다.

  • 01 엔진은 pine_v2 자체 인터프리터입니다. 봉을 하나씩 순회하는 바 단위 이벤트 루프로 실행합니다. 지표를 미리 다 계산해 두고 한 번에 훑는 방식이 아니라, 봉마다 주문과 잔고 상태를 다시 계산합니다.
  • 02 거래소 API 키는 AES-256(Fernet)으로 암호화해 저장합니다. 평문으로 보관하지 않습니다. 복호화 키는 코드가 아니라 환경 변수에서 읽고, 저장소에는 암호문만 남습니다.
  • 03 미지원 Pine 함수가 하나라도 있으면 전체를 거부합니다. 부분 실행으로 그럴듯한 숫자를 만드는 대신, 해석하지 못한다고 먼저 말합니다. 어느 함수 때문인지도 함께 돌려줍니다.
  • 04 리포트는 체결 가정과 데이터 출처를 결과 옆에 인쇄합니다. 체결 시점, 수수료율, 슬리피지, 데이터 구간, 펀딩 반영 여부를 수익률과 같은 화면에 둡니다. 가정을 모르면 수익률도 읽을 수 없기 때문입니다.

이 화면은 프로토타입입니다. 실제 계정 인증은 제품에서 Clerk 가 처리하며, 여기서 입력한 값은 어디로도 전송되지 않습니다.
