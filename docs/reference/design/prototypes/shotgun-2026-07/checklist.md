| `--text-muted` on `--bg-alt`      | **4.49 (AA 미달)** | **5.60** |
| `--warning` on `--warning-subtle` | **4.30 (AA 미달)** | **5.66** |

### ★수용 기준 「라이트 canon ≤ 다크 canon」 판정

| 집합             | 라이트  | 다크 | 판정                 |
| ---------------- | ------- | ---- | -------------------- |
| 인증 라우트 12종 | **171** | 255  | 충족 (라이트가 좋다) |
| 공개 라우트 4종  | 68      | 24   | **미충족**           |
| 전체 16종        | **239** | 279  | 충족                 |

공개 라우트에서 라이트가 나쁜 원인은 **하나의 컴포넌트**다 — 마케팅 푸터의 법적 고지 콜아웃이
`--warning` 을 `--warning-subtle` 위에 얹어 5.66(캐논 5.82 미달, AA 는 통과)이 된다. 캐논은
**「카드 위」 기준**이라 중첩 표면에서 내려가는 것 자체는 다크 정본도 같다(`--card-2` 5.44 / `--card-3` 5.15).
**B2 가 만든 문제가 아니다** — 같은 자리가 구팔레트에서는 4.30 으로 **AA 하드 실패**였다.

## 7.3 ② 사람 판단 축 — 도구가 못 재는 것

1440px 다크에서 캐논 원본과 앱을 나란히 놓고 본 것. **레이아웃·간격·밀도·정보 위계는 도구가 재지 않는다.**

| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `screen-02` ↔ `/dashboard` | KPI 카드 밑 **미터 바** · topbar **검색창 + ⌘K 칩**                                                                               | 상단 **법적 고지 배너**(전 화면 고정)             | ★KPI 3번째 카드 캡션이 **세로로 눌려 3열로 깨진다**("USDT. 활성 세션 종료 거래" 가 좌측에 접히고 숫자가 가운데 뜬다). 캐논은 한 문단으로 흐른다 |
| `screen-03` ↔ `/backtests` | **필터 섹션 통째**(검색·전략·심볼·상태·기간 5종 + 적용됨 칩) · 번호 아이브로 **02** · **CSV 내보내기** · 페이지 크기 **10/25/50** | 상태 **탭 6종**(전체/완료/실행 중/대기/실패/취소) | 표가 1440px 에서 **오른쪽으로 잘린다**(내부 `overflow-x` 컨테이너). 캐논은 같은 폭에 다 들어간다                                                |
| 공통                       | 사이드바 하단 **워크스페이스 라벨**                                                                                               | 우하단 **Clerk dev 위젯**                         | 상단 고지 배너가 topbar 위에 얹혀 캐논 대비 **본문이 한 단 밀린다**                                                                             |

★**표 내부 가로 잘림은 ① 이 구조적으로 못 잡는다.** `runtime-check` 의 overflow 판정은
`document.documentElement.scrollWidth` 만 본다 — 내부 스크롤 컨테이너 안에서 잘리는 열은 그 값을 안 키운다.

★**이 절은 수리 지시가 아니다.** 이번 회차 산출은 표이고, 무엇을 고칠지는 다음 회차가 이 표를 근거로 고른다.
