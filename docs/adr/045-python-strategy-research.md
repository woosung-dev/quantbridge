# ADR-045 — 임의 Python 전략은 격리 실행기에서 연구 백테스트한다

- **상태:** Accepted (2026-10-21 사용자 결정)
- **관련:** ADR-003·004·041·042, PRD §5, [연구 계약](../development/python-strategy-research.md)

## 결정

웹에서 Python을 작성하고 서버에서 백테스트할 수 있게 한다. 실행은 로컬 Linux VM에서 검증한 뒤
앱·DB와 분리된 전용 Linux 실행기로 옮긴다. Python 거래소 주문·데모 자동매매는 이번 범위 밖이다.

1. `PythonStrategy`·불변 버전·`PythonBacktest`를 별도 소유권 원장으로 둔다. 기존 Pine 엔티티의
   `pine_source NOT NULL`·parse/coverage·라이브 계약에 가짜 Pine을 채우지 않는다. 기존 Pine API는 유지한다.
2. API/Celery는 코드를 실행하지 않고 인증된 gateway에 요청한다. gVisor `runsc`가 없으면 차단한다.
   호스트 Python·일반 Docker로 자동 우회하지 않는다. 소스 문자열의 실제 실행은 sandbox 이미지 내부뿐이다.
3. sandbox는 확정 봉을 한 개씩 받고 과거 이력만 누적한다. 전체 미래 데이터·DB·Redis·거래소 키·Docker socket·
   호스트 디렉터리·외부 네트워크를 받지 않는다. 신호를 반환하고 체결·자본·비용은 신뢰된 제어부가 계산한다.
4. 기존 Pine 브로커와 비용·펀딩·보유 경계·통계를 재사용한다. 다음 봉 시가 체결·1배를 기본으로 한다.
   봉 내부 체결과 펀딩 정산 순서가 불명확하면 부분 비용 결과를 통과시키지 않는다.
5. 연구 결과는 출처·명세·소스·파라미터·데이터·실행 환경 해시와 함께 보존한다. 단일 백테스트의 수익과
   별도 기간 통과, 원본 재현, 서버 반영 가능성을 서로 다른 판정으로 둔다.

## 기존 결정과 경계

ADR-042의 **Pine AST → Python View는 계속 읽기 전용**이다. 그 산출물을 실행기에 자동 연결하지 않는다.
ADR-041 생성 화면의 Python도 계속 읽기 전용이며 연구 전략으로 자동 저장하지 않는다. 기존 Pine을
LLM으로 번역해 의미 보존을 가정하고 실행하는 경로도 열지 않는다. 이번 결정은 사용자가 별도로 작성하고
저장한 Python 연구 전략의 실행 경계만 개정한다.

## 이유와 대가

사용자는 한국어 지표 영상·TradingView에서 명시된 규칙을 연구하고, 서로 다른 역할의 지표를 조합한
후보 100개를 BTC·ETH 무기한의 1h·4h·1d에서 반복 검증하기로 결정했다. 기존 Python View로는
새 Python 지표의 실행·수정·배치 실험을 할 수 없다.

임의 코드를 API 프로세스에 넣으면 서버 권한을 함께 주게 된다(ADR-042의 사고 경계). 따라서 별도
실행 환경 비용, 고정 라이브러리, 통신 오버헤드를 수용한다. gVisor도 완전한 무위험을 뜻하지 않는다.
sandbox에는 CPU·메모리·PID·출력·900초 한도를 적용하고, 신뢰된 후처리에는 systemd CPU·메모리
한도를 둔다. 900초는 통계 후처리까지 포함한 전체 응답 시간 보장이 아니다.

## 연구 판정

운영 초기선은 비용 후 수익 > 0, PF ≥ 1.1, 최대낙폭 절댓값 ≤ 25%, 완료 거래 ≥ 30회다.
비용 2배는 참고 지표다. 과거 별도 구간은 `retrospective_not_untouched`로 표시하며 독립적인 사전등록이나
미래 수익의 증거로 쓰지 않는다. 결과·가정·불확실성을 보이는 것이 PRD §5의 목표다.
