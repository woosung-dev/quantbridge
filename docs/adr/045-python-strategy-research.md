# ADR-045 — Python 연구 전략 서비스를 도입하지 않는다

- **상태:** Withdrawn (2026-10-21 사용자 최종 결정)
- **관련:** ADR-003·041·042, PRD §5, [연구 범위](../development/python-strategy-research.md)

## 결정

사용자 Python을 웹에서 편집·저장·서버 백테스트·자동매매하는 서비스를 제공하지 않는다.
Python 전략의 개발·실험은 로컬 연구로 한정한다. 기존 Python View와 AI 생성의 Python 산출물은
계속 읽기 전용이며, 실행되는 정본은 Pine이다.

1. Python 연구실 화면·진입 링크·저장/실행 API와 Celery 작업·주기 회수 작업을 제거한다.
2. 앱과 원격 Python 실행기를 연결하던 HTTP client·gateway·환경설정·systemd 예제를 제거한다.
3. 오프라인 연구 CLI와 gVisor transport, 공통 SL·1.5R 반익절·2R 트레일링 계산은 보존한다.
   앱 API·worker에는 이를 사용자 소스로 호출하는 경로가 없다.
4. 기존 연구 원장 3테이블의 모델 선언과 이미 적용된 마이그레이션은 보존한다. 이번 변경에는
   삭제 DDL·서버 데이터 삭제가 없으며 원장의 신규 저장·실행 경로도 없다.

## 이유와 대가

Python 실행 플랫폼과 공개 전략 공급원은 있지만, 그것만으로 이 서비스의 Python 편집·실행 수요가
입증되지는 않는다. 사용자 코드를 실행하면 격리·자원 한도·패키지·오류 복구·주문 권한의 운영 책임이
추가된다. 사용자는 Python 개발자는 로컬에서 연구하고 서비스는 Pine 경로를 유지하는 방향을 선택했다.

원장의 선언을 유지하는 것은 이미 적용된 DB 이력을 코드 제거와 함께 삭제하지 않기 위해서다.
해당 데이터의 영구 삭제는 별도 범위이며 여기서 승인하거나 예약하지 않는다.

종전 도입 결정과 구현 계약 원문은 PR #914의 커밋 `66061cd2`에 있다. 이 결정은 Pine의 부분 수량·
취소·청산 보호 개선이나 Python으로 작성된 백엔드 자체를 제거하는 결정이 아니다.
