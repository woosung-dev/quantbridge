# ADR-046 — 생성 방식과 실행 언어를 교차 평가하고 검증된 승자를 도입한다

- **상태:** Accepted (2026-10-22 사용자 결정)
- **관련:** ADR-003·041·042·045, PRD §5, [실행 계약](../development/sol-strategy-lab.md)

## 결정

자연어 전략을 Sol 6.1로 생성하고 Pine·Python·TypeScript에서 실제 실행해 비교한다.
제품 실행 언어를 Pine으로 미리 고정하지 않는다. 독립 검증을 통과한 방식·언어 조합을
선정한 뒤 해당 실행 경로를 제품에 연결한다. 이는 ADR-045의 영구 미도입 범위를 대체한다.
기존 Python 연구 원장과 철거한 서비스를 검증 없이 복구한다는 결정은 아니다.

1. 생성 방식은 직접 생성, 제한 수정, 타입 명세와 결정론 컴파일의 세 경로다.
2. 생성 모델은 `gpt-6.1-sol`, reasoning effort는 high다. 실행 중 LLM 매매 판단은 없다.
3. 생성 코드는 완료 봉과 확정 포지션으로 진입·무효화 의도를 계산한다. 체결·비용·펀딩·
   공통 SL·반익절·트레일링은 신뢰된 실행 계층이 소유한다.
4. Python·Node 실행과 TypeScript 컴파일은 자격증명·호스트 파일·네트워크가 없는
   자원 제한 격리 환경에서만 수행한다. 일반 호스트 실행으로 우회하지 않는다.
5. 승자 선정은 요청 충실도·원장 일치·재현성을 우선하며 수익성은 별도 보고한다.
   과거 탐색 구간을 미사용 검증으로 재명명하지 않는다.

## 이유와 대가

Pine 전용이라는 선결정은 Python·Node가 동일 전략을 더 충실하게 표현하거나 더 쉽게
운영할 가능성을 실제로 비교하지 못하게 한다. 반대로 언어별로 다른 체결 엔진을 쓰면
차이를 언어에 귀속할 수 없다. 공통 매매 계약과 독립 기준을 둔 교차 평가를 채택한다.

다중 언어 격리·타입 검사·SDK·재시작과 주문 보호의 운영 책임이 추가된다. 따라서 연구
실행 성공, 백테스트 의미 검증, 제품 연결, 실제 Demo 관측을 서로 다른 상태로 공개한다.
Pine의 기존 경로와 Python View의 읽기 전용 계약은 각자의 기존 의미를 유지한다.

## 활성화 경계

이 ADR은 구현·격리 연구·작업 브랜치 PR을 허용한다. 운영 배포·운영 DDL·실제 거래소
주문을 승인하지 않는다. 승자·근거·실행 제약은 구현 계약과 재현 가능한 연구 산출물에 둔다.
