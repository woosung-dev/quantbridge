//@version=5
// 빠른 이동평균이 느린 이동평균을 상향 돌파하면 롱으로 진입한다.
// 하향 돌파하면 포지션을 닫는다. 숏 진입은 쓰지 않는다.
strategy("MA Crossover 20/50", overlay=true, initial_capital=10000,
     default_qty_type=strategy.percent_of_equity, default_qty_value=90)

fastLength = input.int(20, title="빠른 이동평균", minval=2)
slowLength = input.int(50, title="느린 이동평균", minval=5)

fastMa = ta.sma(close, fastLength)
slowMa = ta.sma(close, slowLength)

goLong  = ta.crossover(fastMa, slowMa)
goShort = ta.crossunder(fastMa, slowMa)

if goLong
    strategy.entry("Long", strategy.long)

if goShort
    strategy.close("Long")

plot(fastMa, color=color.orange, title="Fast MA")
plot(slowMa, color=color.blue, title="Slow MA")

이 화면의 스크립트와 파싱 결과는 프로토타입용 샘플입니다. 실제 판정은 서버의 지원 함수 사전으로 결정되며, 원문은 변환 없이 pine_v2 인터프리터가 바 단위로 실행합니다.
