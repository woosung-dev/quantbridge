## 4. 만장일치 결론

1. **B 는 탈락.** 4명 전원이 최하위 또는 차하위. 가짜 페르소나 "김지훈", 가짜 알림 배지 3, 죽은 토글, 미로드 폰트, x축이 3개월과 12개월을 같은 폭으로 표시(4.9배 왜곡), 그리고 24지표 과제에 DENSITY 3.
2. **A 는 정체성 최강, 신뢰성 최약.** anti_slop 8.0 으로 "AI 가 절대 안 만드는 결과물" 이지만, 밀도를 정보구조가 아니라 **폰트 축소로 샀고**(7.8px × 2.92:1), 차트 축이 비선형이며, 칼마가 자기 라벨로 반증된다.
3. **C 가 베이스.** 유일하게 축이 선형이고, 지표 간 산술이 검산을 통과하며, "이 숫자가 성립하는 조건"(체결 시점·수수료·슬리피지·펀딩 미반영·결측 봉 0)을 화면에 인쇄한다.
4. **결함 구조가 결정적.** C 의 미결은 전부 국소 수정(`outline:none` 삭제, 애니메이션 단축, 산술 재계산)인 반면, A 는 타이포·컬러 토큰 전면 재산출, B 는 밀도 다이얼 재설정이 필요하다.

> **정확한 숫자에 밀도를 얹는 것은 CSS 작업이지만, 밀도 있는 오답을 정확하게 만드는 것은 재작성이다.** — design-taste-frontend

## 5. 세 변형 공통 배송 블로커

- **`outline: none` 으로 키보드 포커스 사망** — A(`.field input`), B(`.search/.select:focus`), C(`.input/.select`, `.searchbox input`). 디자인 방향과 무관하게 이식 전 필수 수정.
- **아이콘 전용 축소 구간의 `aria-label` 부재** — 768~1024px 에서 내비 라벨이 `display:none` 되는데 접근 가능한 이름이 없다. 세 변형 공통.
- **인라인 SVG 아이콘 직접 드로잉** (§3.C/§9.E) — 세 변형 공통. Next.js 이식 시 Phosphor 또는 Tabler 로 교체.

### 이식 (B → C) — 딱 두 가지

- 타깃 크기 규격(nav/btn 42px, icon-btn 40px)을 C 의 38px 계열에 덮어쓰기.
- 세그먼티드 컨트롤 **중첩 반경**(외부 10px / 내부 7px) — C 의 12-in-12 탭 반경 문제의 정답.

### 버릴 것

- C 의 `.meter` 채워진 트랙 4개 (기준 없는 비율 막대, §9.F) — **4명 전원 일치**.
- C 의 번호 아이브로 7개 → 3개 이하 + 마이크로 메타 문장 3개 삭제.
- C 의 `.draw` 1400ms (그 사이 주 데이터 계열이 화면에 없음).
- A 의 `--ink-4` 텍스트 사용, A/B 의 4-미들닷 메타 줄.

### 착수 순서

1. `outline:none` 제거 + 내비 `aria-label` → 우선순위 1 잔여 0
2. `.draw` 제거, `.rise` 520 → 320ms
3. 거래 통계 재계산 (승률 58.60% 기준 평균수익 200.59 / 평균손실 118.50 / 손익비 1.69)
4. A 의 테이프·판독 패널·키보드 칩·밀집 격자 이식 → density_fit 7.5 → 9
5. 루트 14px 유지, 최소 폰트 12px 하한 확보

## 6.5. 최종 결정 — 병합안(D) 기각, C 원형 확정 (2026-07-19)

§6 의 병합 사양대로 `variant-d.html` 을 실제로 만들었으나, **사용자 검토 결과 기각**됐다. C 원본이 더 낫다는 판단이다.

- **원인 추정.** A 의 밀도 장치(24셀 헤어라인 격자·실행 파라미터 테이프·크로스헤어·키보드 칩)를 얹자 C 가 선택받은 이유였던 **차분한 가독성과 재무제표식 스캔감**이 손상됐다. 패널은 "밀도 부족(density_fit 7.5)"을 약점으로 봤지만, 실사용자에게는 그게 약점이 아니라 **의도된 여백**이었다.
- **교훈.** 4-평가자 정량 집계가 방향(C)은 맞혔지만, **개선안의 방향까지 맞히지는 못했다.** 이식이 항상 개선은 아니다. 코드 지표로 측정되는 density_fit 과 실제 사용 피로도는 다른 축이다.
- **조치.** D 는 레포에서 제거하고 scratchpad 에 보관(복구 가능). 확정안은 **C 원형 + 안전 수정 3종**.

### 적용한 안전 수정 (외형 불변)

| #   | 수정                                                                        | 근거                                                                               |
| --- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| ①   | `.input/.select` 의 `outline:none` 제거 + `.searchbox:focus-within` 링 추가 | `:focus-visible`(L118)이 소스 순서·특이도에 밀려 키보드 포커스가 완전히 비가시였음 |
| ②   | 사이드바 nav `<a>` 6개에 `aria-label`                                       | 768~1024px 에서 `.label { display:none }` 이 접근 가능한 이름을 제거               |
| ③   | 거래 통계 재계산. 200.59 / 118.50 / 1.69                                    | 109승·77패 · 총이익 21,864.30 / 총손실 9,124.12 와 정합                            |

### 의도적으로 적용하지 않은 것 (사용자 픽 존중)

미터 바 4개(4명 전원 제거 권고), 번호 아이브로 7개(루브릭 상한 3), 최소 폰트 상향. **모두 C 의 외형을 바꾸는 변경이라 제외했다.** 필요해지면 언제든 적용 가능하다.
