### ★pin 의 비용 — 「C2 가 0 이 된다」는 거짓이다 (2026-08-10 확정)

**코드 근거 3줄** (`backend/scripts/soak_gate_predicate.py`):

```python
window_start = disq[-1].at                                    # :614  창 시작 = 마지막 **실격**

```

**창을 리셋하는 것은 실격뿐이다.** `pin` 은 `window_start` 에 등장하지 않는다.

**실측이 확증한다** — 게이트가 스스로 내는 「귀속 창 3개」에 고정 sha 가 **두 종류**다
(`3f8af9dfe78e` → `fdc53c04a929`). 2026-08-08 에 pin 을 했고 **그 이전 15.30h 창이 지금도 목록에
살아 있다.** 산술도 맞는다: `15.3007 + 0.0133 + 26.6558 = 41.97h` = 그 시점 C1.

⇒ **pin 은 attribution 을 sha 로 쪼갤 뿐, 과거 창을 배제하지 않는다.**
⇒ C1(합)도 C2(max)도 pin 을 넘어 **보존된다.**

★**오해의 근원**: `soak-stack.sh:185` 가 `down` 을 요구하며 **「연속 창은 끊긴다」**고 말한다.

### 증명한 것과 못 한 것을 **합쳐 말하지 마라**

프로덕션 유도는 분기의 **도달·종결**만 증명한다. 계측 실패 봉쇄 같은 것은 **오프라인 결정론
테스트**가 증명하며, 프로덕션에서 유도하려면 multiproc 디렉터리를 망가뜨려야 해서 소크 중 금지다.
층을 나눠 표로 적어라 — 한 줄로 합치면 다음 사람이 「검증 완료」로 읽는다.
