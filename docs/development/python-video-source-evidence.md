# 영상에서 가져온 Python 전략의 출처 계약

영상에서 확인한 규칙, 연구자가 정한 수치, 실행기의 체결 가정을 구분한다.
수익률·승률에 대한 발표자의 주장은 독립 검증의 증거로 사용하지 않는다.

## 근거를 확인하는 방법

1. 공개 페이지의 설명과 스크립트 UI를 확인한다. 기존 사용자 프로필·쿠키를 가져오지 않는다.
2. 공개 영상이 정상 다운로드되면 480 해상도 미디어를 로컬 Whisper로 전사한다. 유료 API에 미디어를 보내지 않는다.
3. 지표 종류·기간·임계값·진입·청산 설명의 해당 시각을 원본 프레임과 대조한다. 전사만으로 숫자를 확정하지 않는다.
4. URL·시각·확인된 규칙·미확인 항목을 기록하고, 미디어와 모델 revision·해시를 보존한다. 원문 전사·미디어는 `runs/`에만 둔다.

공개 YouTube UI의 스크립트 요청은 세 영상 모두 `400 FAILED_PRECONDITION`,
자막 요청은 `200 / 0 bytes`였다. 로컬 전사로 음성 전체를 확보했고 선택 구간의 영상
프레임을 대조했다. 로그인 필요성은 확인하지 않았다. 도구·미디어 해시·모델 revision은
[미디어·전사 근거](../../runs/video-rule-research/media-asr-provenance.json),
시각별 규칙은 [근거 목록](../../runs/video-rule-research/rule-observations.json)에 있다.
이 파일들은 재생성 가능한 로컬 산출물이며 커밋하지 않는다.

## 100개 연구 가설과 원본 재현의 구분

- **원본 재현:** 필수 계산식·파라미터·진입·청산·사이징을 출처로 확정하고, 설명의 예시와 구현 신호를 대조한 뒤 표시한다. 미확인 항목을 관행적인 기본값으로 채우지 않는다.
- **착안한 연구 가설:** 스퀴즈 간격, 기울기 기간, RSI 설정처럼 연구자가 정한 값은 별도 가설·코드 버전으로 기록한다. 이 100개 후보가 원본 전략 100개라는 의미는 아니다.
- **시장·체결 변형:** 5분봉 CFD 예시를 Bybit BTC/ETH의 1시간·4시간·일봉으로 옮기거나, 봉 내부 터치 청산을 확정봉 신호와 다음 봉 시가 청산으로 바꾸면 새로운 변형이다. 원본의 과거 수익률을 승계하지 않는다.
- **검증 후보:** 출처가 분명해도 백테스트 통과는 별도다. 데이터·비용·독립 기간 검증과 운영 반영 기준은 [Python 전략 연구 계약](python-strategy-research.md)을 따른다.
