# 이슈 트래커: 기존 문서 백로그

- 열린 작업: `docs/backlog.md`의 ACTIVE·PARTIAL 항목.
- 보류 작업: `docs/backlog-deferred.md`의 DEFERRED 항목.
- 다음 작업의 유일한 진입점: `docs/status.md`의 살아 있는 `다음 행동 =`.
- 등록·조회·갱신은 기존 BL-ID와 문서 형식을 따른다. ID를 재사용하지 않는다.
- 종결 항목은 기존 규칙에 따라 삭제하고, 이력은 git에서 조회한다.
- 스킬의 이슈 발행·조회 지시는 이 문서 원장의 편집·조회로 수행한다.
- GitHub Issue나 `.scratch/`에 동일 작업을 중복 생성하지 않는다.
- PR은 기존 작업 브랜치·PR 절차를 따른다.
