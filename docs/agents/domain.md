# 도메인 문서

구조는 single-context다.

- 코드 탐색 전에 루트 `GLOSSARY.md`를 읽는다.
- 작업 영역과 관련된 `docs/adr/`의 결정을 읽는다.
- 용어 정의와 피해야 할 동의어는 `GLOSSARY.md`를 따른다.
- 확정된 용어는 `GLOSSARY.md`에 즉시 갱신한다.
- 정의는 용어당 1~2문장으로 유지한다.
- 구현 상세·실행 계약·작업 이력은 용어집에 넣지 않는다.
- 관계·구현 계약은 기존 `docs/domain/`과 관련 설계 문서를 따른다.
- ADR과 충돌하는 제안은 충돌과 이유를 명시한다.
