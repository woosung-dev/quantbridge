# Lessons Learned

> AI가 실수를 교정받을 때마다 이 파일이 업데이트됩니다.
> 반복되는 패턴은 .ai/common/ 또는 .ai/stacks/ 규칙으로 승격합니다.

---

## 작성 규칙

- 새 교훈은 아래 포맷으로 추가한다
- ID는 순차 부여 (LESSON-001, 002, ...)
- 동일한 실수가 반복되면 새 항목을 만들지 않고 기존 항목의 **반복 횟수**를 증가시킨다
- 반복 횟수가 3 이상이면 **승격 대상**에 대상 규칙 파일을 기입한다
- 승격 완료된 항목은 `[승격 완료]` 표시 후 다음 정리 시 삭제한다

## 포맷

### LESSON-{NNN}: {제목}
- **상황:** 무엇을 하다가 문제가 발생했는가
- **원인:** 왜 발생했는가
- **해결:** 어떻게 해결했는가
- **반복 횟수:** 1
- **승격 대상:** ✗ (또는 → `.ai/stacks/nextjs/frontend.md` §N)
